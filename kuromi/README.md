# Kuromi 英语闯关 · 四年级上册

面向小学四年级学生的**库洛米（Kuromi）主题英语闯关网页**：单元卡片闯关 + 艾宾浩斯记忆复习 + 口语朗读检测。库洛米会在每次闯关成功后用英语夸赞你，并**把夸赞读出来**。

## 快速开始

**务必用本地服务器打开**（语音朗读与语音识别需要 localhost 安全环境）：

- 双击 **`start.bat`**（Windows）→ 自动启动本地服务器并打开浏览器
- 或手动：在项目根目录执行 `python -m http.server 8000`，访问 `http://localhost:8000/kuromi/`

> 直接双击 `kuromi/index.html` 也可以浏览和闯关，但**语音功能（朗读/识别）会不可用**。

## 教材同步

知识库与人教 **PEP（2024 版）** 小学英语四年级上册（安徽合肥通用教材 · 2025 秋）**单元主题同步**，全册 6 个单元：

| 单元 | 主题 | 内容 |
|---|---|---|
| Unit 1 | Helping at home | 在家帮忙（clean/sweep/cook…） |
| Unit 2 | My friends | 我的朋友（tall/friendly/glasses…） |
| Unit 3 | Places we live in | 我们住的地方（bedroom/kitchen/garden…） |
| Unit 4 | Helping in the community | 帮助社区（park/library/neighbour…） |
| Unit 5 | The weather and us | 天气（sunny/rainy/windy…） |
| Unit 6 | Changing for the seasons | 季节变化（spring/autumn/swim…） |

每单元 12 个核心单词（共 72 个）+ 3 组重点句型。词汇基于已确认的教材单元主题整理；如需校正个别单词，直接编辑 `data/units.js` 即可（格式见文件头注释）。

## 功能

- **起点自定**：首次进入选择"从第几单元开始"，更早的单元自动标记为已会并进入记忆复习；单元地图上也可整单元"标记已会"或逐词跳过
- **闯关**：四种题型混合（听音选词 / 英→中 / 中→英 / 拼写），每关最多 10 词，答对得星
- **艾宾浩斯记忆计划（简化版）**：新学 → 明天 → 3 天 → 7 天 → 14 天，四轮后"毕业"；答错自动回炉重学；**标记"已会"的词同样按计划进复习**
- **口语复习**：看到中文 + 图片 → 听发音 → 点麦克风大声读出来，浏览器语音识别检测读得对不对（Chrome / Edge 支持）
- **英音 / 美音切换**：设置页一键切换，朗读、识别、口音全部跟随
- **库洛米夸赞**：答对单题有短夸赞（"Great!"），通关有大夸赞（"Perfect! You're a star!"），全部用语音朗读；答错是傲娇鼓励（"Try again! You can do it!"）
- **激励**：星级评定 + 每单元通关获得🦴骷髅徽章

## 语音与数据

| 项目 | 说明 |
|---|---|
| 朗读（TTS） | 浏览器在线语音合成（英音 en-GB / 美音 en-US），**不下载、不占用本地容量** |
| 口语识别 | Web Speech API（需 Chrome 或 Edge；若浏览器不支持会降级为"跟读自评"） |
| 进度存储 | 浏览器 localStorage（本机），可在设置页**导出进度**（JSON）备份 |
| 重置 | 设置页"重置全部进度"可重新开始 |

## 文件结构

```
kuromi/
├── index.html       页面（首页/单元地图/闯关/复习/设置 + 库洛米 SVG 角色）
├── styles.css       库洛米主题（黑·白·粉 / 骷髅 / 朋克可爱）
├── app.js           逻辑（闯关状态机/艾宾浩斯调度/口语识别/TTS/设置）
├── data/units.js    知识库（6 单元 72 词 + 句型，可自行编辑）
├── start.bat / start.ps1   一键启动（本地服务器 + 打开浏览器）
└── README.md
```

## 与 1.0（意象笺 · 玉兰诗经）的关系

2.0 复用了 1.0 的技术框架（纯前端单页、数据文件驱动、localStorage 存储、零依赖），完全独立运行于 `kuromi/` 目录，两者互不影响。

## 说明

- 库洛米形象为致敬三丽鸥角色风格的原创 SVG 绘制，仅用于个人学习用途。
- 语音识别依赖浏览器与网络（在线服务），识别结果与口音、环境有关，孩子读不准时会给提示并允许重试。
