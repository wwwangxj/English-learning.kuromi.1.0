# 意象笺 · 玉兰诗经

一部会落花的写作灵感簿：以《诗经》为壤，以玉兰为灯。

一个**扩展思维、积累写作意象**的小工具：内置 60 枚从《诗经》采撷的意象与 12 个写作场景，支持意象碰撞、随想积累与 JSON 导入扩展。

## 快速开始

- **直接使用**：双击打开 `index.html` 即可（零依赖、纯前端、离线可用，数据仅存于本机浏览器 localStorage）。
- **本地服务器**（可选，体验一致）：`python -m http.server` 或 `npx serve` 后访问。

## 功能

| 模块 | 说明 |
|---|---|
| 扉页 | 玉兰主题开场，**点击枝头玉兰会飘落花瓣**，"推门而入" |
| 意象墙 | 60 枚诗经意象卡片流；按类别 / 感官筛选，情绪筛选为可折叠面板；支持关键词搜索 |
| 意象详情 | 原文、出处、释义、意象解析（为什么美、写作怎么用）、写作提示；每张卡片可写"我的随想" |
| 意象碰撞 | 随机 1 意象 × 1 场景，可选"情感方向"（折叠、不强迫），一键生成写作火花，随想可保存 |
| 随想簿 | 汇总所有碰撞记录与卡片随想，可跳回原意象 |
| 导入 | 预留接口：JSON 导入自定义意象与场景（格式见下） |

## 数据存储

全部数据保存在浏览器 localStorage（本机、不联网）：

| Key | 内容 |
|---|---|
| `yx_notes_v1` | 卡片随想（意象 id → { text, ts }） |
| `yx_collides_v1` | 碰撞记录数组 |
| `yx_imported_v1` | 导入的自定义意象与场景 |

> 注意：清理浏览器站点数据会清空这些内容。需要备份/迁移时，可从 DevTools → Application → Local Storage 导出。

## 导入格式（JSON）

在"导入"页粘贴 JSON，或选择本地 `.json` 文件。两个字段都可选，**同名（`name`）会覆盖已有条目**。示例见 [`data/import-example.json`](data/import-example.json)。

```json
{
  "imagery": [
    {
      "name": "意象名（必填）",
      "category": "类别，如 植物/动物/天象/山水/器物/人物/时令/其他",
      "senses": ["视觉", "听觉", "嗅觉", "触觉", "味觉", "情思"],
      "moods": ["情绪标签，可多个，如 思念、苍凉"],
      "source": "出处，如 个人观察 / 《某某篇》",
      "text": "摘句原文",
      "meaning": "释义",
      "analysis": "意象解析：为什么美、写作时怎么用",
      "prompt": "写作提示"
    }
  ],
  "scenes": [
    { "name": "场景名（必填）", "description": "场景描写" }
  ]
}
```

字段说明：除 `name` 外全部可选；`category` 缺省为"其他"；`senses`/`moods` 缺省为空数组。导入的条目会与内置素材合并展示，内置 60 枚不受影响。

## 文件结构

```
├── index.html           页面骨架（扉页 / 意象墙 / 碰撞 / 随想簿 / 导入 / 详情）
├── styles.css           玉兰主题样式（含花瓣动画）
├── app.js               应用逻辑（零依赖）
├── data/
│   ├── imagery1.js      内置诗经意象（一）：植物 20 + 动物 17
│   ├── imagery2.js      内置诗经意象（二）：天象 10 + 山水 4 + 器物 7 + 时令 1 + 人物 1
│   ├── scenes.js        内置场景库（12 个）
│   └── import-example.json  导入格式示例
└── README.md
```

## 2.0 预留

- **主题系统**：样式以 CSS 变量（`:root`）组织，后续可加主题切换（如暗色沉浸风、其他花木主题）。
- **素材扩充**：内置素材为独立数据文件，导入接口已就绪，可直接扩充意象与场景。
- **导出**：`localStorage` 数据可通过 DevTools 导出，后续可加一键导出/备份按钮。
