# 项目总览

本项目包含两个独立的小应用（纯前端、零依赖），根首页 `index.html` 会自动进入 **库洛米英语闯关**。

## 应用

| 应用 | 目录 | 说明 |
|---|---|---|
| **库洛米英语闯关** | [`kuromi/`](kuromi/README.md) | 面向小学四年级的英语闯关 + 记忆复习，与人教PEP(2024)四年级上册同步，含语音朗读/识别。**根首页会直接进入这里**。 |
| **意象笺·玉兰诗经** | [`imagery/`](imagery/) | 1.0：诗经意象积累与写作灵感工具（玉兰主题）。当前归类于 `imagery/`，后续可拆分为独立项目。 |

## 启动

- 库洛米：`kuromi\start.bat`（本地服务器，语音可用）
- 意象笺：`imagery\index.html`（双击打开）

## GitHub Pages

部署时选 `/ (root)`，站点主页自动进入库洛米英语闯关：
- 库洛米闯关：`https://<用户名>.github.io/<仓库名>/`
- 意象笺：`https://<用户名>.github.io/<仓库名>/imagery/`
